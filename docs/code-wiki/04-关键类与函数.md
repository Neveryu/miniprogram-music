# 关键类与函数

项目没有传统 JavaScript `class`。主要运行单元是微信小程序 `App`、`Page`、`Component` 和 `musicApp` 云函数。

## App 全局对象

| 函数 | 作用 |
| --- | --- |
| `onLaunch()` | 检查更新、读取本地缓存的用户资料、读取系统信息并动态初始化 `wx.cloud` |
| `readStoredUserInfo()` / `saveUserInfo(userInfo)` | 读写本地用户缓存，用于冷启动首屏和登录态更新 |
| `onLogin(callback)` | 注册登录成功回调，返回取消注册函数；需要登录后刷新数据的页面各自订阅 |
| `notifyLogin(userInfo)` | 保存用户信息并通知全部登录回调 |

应用不在客户端保存第三方音乐服务或业务鉴权凭据。微信身份由云函数运行环境提供。

## 云函数入口

`cloudfunctions/musicApp/index.js` 是统一服务端入口。

| 函数 | 作用 |
| --- | --- |
| `getUserByOpenid(openid)` | 根据 OPENID 查询已完成登录的用户 |
| `saveLoginUser(openid, payload)` | 校验登录资料并创建或更新用户 |
| `ensureDefaultRoom(user)` | 查询或创建唯一默认房间 |
| `healCurrentSong(room)` | 读时自愈：`current_song` 指向已删除的队列项时，按 CAS 条件修正为队列首项或清空，避免悬空指针误拦点歌 |
| `sendMessage(payload, user)` | 校验并写入聊天消息；文字发送前调用 `checkTextSecurity`（`security.msgSecCheck`，异常时放行）；文本携带 `client_msg_id` 时按 `_openid + room_id + client_msg_id` 去重，支持失败重发幂等 |
| `recallMessage(payload, user)` | 校验消息所有者或房主权限后撤回；仅对 `img` / `voice` 且位于 `messages/` 下的文件，在确认没有其他消息引用后删除，避免误删头像或他人媒体 |
| `addFavorite(payload, user)` | 保存用户收藏歌曲（按 `_openid + source + mid` 去重） |
| `favoriteList(payload, user)` | 分页返回用户收藏（`page` 参数每页 30 条；`filter: 'children'` 只返回儿歌分类，否则只返回非儿歌的「我的歌曲」，两者互斥；返回项附带 `children` 标记；单条损坏记录会被跳过；顶层 `hasMore` 表示是否还有下一页） |
| `toggleFavoriteChildren(payload, user)` | 将收藏记录标记为儿歌 / 移出儿歌 |
| `addSong(payload, user, playNow)` | 写入播放队列并按需更新当前歌曲；`playNow` 仅限房主，队列达到 100 首时拒绝新歌曲 |
| `passSong(payload, user)` | 切换到下一首；任意登录用户可调用，仅校验队列项一致性 |
| `autoPassSong(payload, user)` | 播放资源失效时自动切歌（系统行为，不校验房主） |
| `finishSong(payload)` | 处理歌曲自然结束并推进队列 |
| `switchToNextSong(room, options)` | 移除当前播放歌曲并切到队列下一首；`autoPass` 传入 `refillWhenEmpty` 时会先补一次歌再切，避免唯一歌曲失效后队列直接清空 |
| `refillQueue(payload, user)` | 自动补歌：正常模式「我的歌曲收藏 / 缓存 / 客户端 WS 提示词候选」按 5:3:2 随机混入队列；儿歌模式「儿歌收藏 / 客户端 WS 词池候选」按 3:2。候选由小程序搜索后提交，云函数不再请求音乐接口；收藏/缓存候选只保留 `netease` / `tencent` |
| `getFavoriteSongs(user, childrenOnly)` | 收藏候选：`childrenOnly` 为真只取标记为儿歌的收藏，否则排除儿歌收藏（与收藏页「我的歌曲 / 儿歌」互斥语义一致）；只返回 `netease` / `tencent` 来源 |
| `setChildrenMode(payload, user)` | 一键儿歌开关：开启时置位、清空队列并优先播放一首「儿歌」收藏；没有收藏时返回 `has_song: false`，由客户端通过 WS 搜索首曲 |
| `getNeteaseLyric(mid)` | 调用网易云官方歌词接口并解析为播放器歌词结构，带 30 分钟缓存 |
| `getNeteaseCovers(mids)` | 调用网易云官方歌曲详情接口补全缺失封面，单次最多 30 个，命中缓存 24 小时 |
| `exports.main(event)` | 先获取可信 OPENID；仅当没有 OPENID 且 `Type === 'Timer'`、`TriggerName === 'refillPlaybackQueue'` 时进入定时补歌分支（客户端伪造字段仍带 OPENID，不会命中），其余按动作分发 |

## 首页初始化

| 函数 | 作用 |
| --- | --- |
| `onLoad()` | 初始化播放器并静默查询当前微信用户对应的业务账号 |
| `getMyInfo(reloadRoom)` | 调用云函数加载已有用户；不存在时保留登录入口 |
| `getRoomInfo()` | 加载固定默认房间、历史消息并建立实时监听 |
| `handleBootstrapFailure()` / `scheduleBootstrapRetry(kind)` | 冷启动身份或房间请求失败时释放 loading，按 3 秒间隔最多重试 3 次；耗尽后提示重新进入小程序 |
| `notifySongEnded(songInfo, attempt)` | 歌曲自然结束后调用 `song/ended`；传输失败最多重试 3 次，仍失败时回退本地补歌并提示手动切歌 |
| `refillPlaybackQueue()` | 队列不足时先确认长度，再通过 WS 搜索候选并调用 `song/refill`；游客不发起补歌 |
| `watchCloudData()` | 监听 `messages` 和 `rooms` 集合；监听报错后按指数退避重建（3 秒起、最长 30 秒，收到数据后重置），页面卸载后停止重连；`rooms` 回调会裁剪补歌锁与备用缓存等内部字段后再写入 `roomInfo` |
| `closeCloudWatchers()` | 页面卸载时关闭数据库监听器 |

首页固定使用 `room_id = 1`，不再从场景参数或 Storage 读取房间号。

## 实时监听

`watchCloudData()` 建立两个数据库监听器：

- `messages`：按时间排序后映射为聊天消息，并保留最近 `historyMax` 条。
- `rooms`：更新默认房间资料；`current_song` 发生变化时调用 `playMusic()`。

首页使用云数据库监听房间和消息；网易云歌单、用户及歌单详情页使用 `utils/jusicWsApi.js` 的 SockJS + STOMP WebSocket 客户端。

## 音乐函数

| 函数 | 作用 |
| --- | --- |
| `getMusicLrc()` | 仅网易云歌曲调用云函数获取歌词，其他来源直接清空；前奏阶段保持空白，不提前显示最后一行 |
| `playMusic(msg, resumePosition)` | 优先复用歌曲已有直链，缺失时通过客户端 WS 点播获取；`resumePosition` 用于同曲暂停后恢复播放 |
| `startPlayback(msg, url, announce = true)` | 设置背景播放器：直接取用切歌/进房时冻结的 `__seekPosition`（不把 WS 解析耗时计入 seek），并启动播放失败 watchdog；`announce` 控制是否发送系统消息 |
| `computePlaybackSeekPosition(msg)` | 基于校准后的服务端 `since` 计算进房/重连接的起播偏移，按歌曲时长封顶 |
| `schedulePlaybackGuard(msg)` | 新直链 6 秒内未真正开始播放时重试一次点播，仍失败则自动切歌 |
| `showSongMenu()` | 显示收藏、切歌和音乐开关操作 |
| `refreshCarFavState()` | 查询驾驶模式当前歌曲收藏状态并推送 `sendFavState`；游客直接推登录态，查询失败按未收藏兜底 |
| `toggleFavoriteFromCar(payload)` | 驾驶模式收藏/移除收藏切换；按 `mid` 丢弃切歌后的过期操作，成功/失败均回推按钮状态 |
| `longPressPassTheSong()` | 驾驶模式切换歌曲 |

歌曲必须包含 `mid`、`name`，播放地址必须是 HTTPS 直链。

## 消息函数

| 函数 | 作用 |
| --- | --- |
| `getMessageList()` | 通过云函数加载初始历史消息 |
| `sendMessage(e)` | 乐观展示文本消息并调用云函数写入数据库；失败后重发同一段文本会复用 `client_msg_id`，由服务端去重 |
| `rollbackPendingMessage(message, replyTarget)` | 发送失败或未登录时移除最后一条本地临时消息并恢复输入内容 |
| `chooseImage()` | 按临时文件扩展名上传图片到云存储并发送云文件 ID；登录失效或业务失败时删除刚上传的文件 |
| `deleteCloudFile(fileId)` | 删除客户端刚上传的云文件；仅在 401 或业务失败确认消息未入库时调用 |
| `startVoiceRecord()` / `stopVoiceRecord()` | 按住开始录音，松开后停止并发送 |
| `uploadVoice(result)` | 上传语音到云存储并发送文件 ID、时长和引用 ID |
| `playVoice(e)` | 使用 `InnerAudioContext` 播放聊天语音 |
| `longTapToMessage(e)` | 提供撤回和引用操作 |
| `autoScroll()` | 将聊天视图滚动到底部 |

消息写入后由数据库监听刷新正式列表。请求失败时会移除本地临时消息并恢复输入内容。

## 导航与交互

`mainMenuClicked()` 保留驾驶、儿歌、点歌、已点（播放队列）、收藏和提示词入口。

## 用户页面

| 函数 | 页面 | 作用 |
| --- | --- | --- |
| `chooseWechatAvatar(e)` | 登录 | 上传微信头像并创建或读取用户 |

云函数使用微信身份上下文识别用户，客户端不能主动切换该身份。
