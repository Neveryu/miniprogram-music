# 关键类与函数

项目没有传统 JavaScript `class`。主要运行单元是微信小程序 `App`、`Page`、`Component` 和 `musicApp` 云函数。

## App 全局对象

| 函数 | 作用 |
| --- | --- |
| `onLaunch()` | 检查更新、读取本地缓存的用户资料、读取系统信息并动态初始化 `wx.cloud` |
| `readStoredUserInfo()` / `saveUserInfo(userInfo)` | 读写本地用户缓存，用于冷启动首屏和登录态更新 |
| `onLogin(callback)` | 注册登录成功回调，返回取消注册函数；需要登录后刷新数据的页面各自订阅 |
| `notifyLogin(userInfo)` | 保存用户信息并通知全部登录回调 |
| `showLogin()` | 打开微信登录页 |

应用不在客户端保存第三方音乐服务或业务鉴权凭据。微信身份由云函数运行环境提供。

## 云函数入口

`cloudfunctions/musicApp/index.js` 是统一服务端入口。

| 函数 | 作用 |
| --- | --- |
| `getUserByOpenid(openid)` | 根据 OPENID 查询已完成登录的用户 |
| `saveLoginUser(openid, payload)` | 校验登录资料并创建或更新用户 |
| `ensureDefaultRoom(user)` | 查询或创建唯一默认房间 |
| `sendMessage(payload, user)` | 校验并写入聊天消息 |
| `recallMessage(payload, user)` | 校验消息所有者或房主权限后撤回 |
| `addFavorite(payload, user)` | 保存用户收藏歌曲（按 `_openid + source + mid` 去重） |
| `favoriteList(payload, user)` | 分页返回用户收藏（`page` 参数每页 30 条；`filter: 'children'` 只返回儿歌分类，否则只返回非儿歌的「我的歌曲」，两者互斥；返回项附带 `children` 标记） |
| `toggleFavoriteChildren(payload, user)` | 将收藏记录标记为儿歌 / 移出儿歌 |
| `addSong(payload, user, playNow)` | 写入播放队列并按需更新当前歌曲；`playNow` 仅限房主 |
| `passSong(payload, user)` | 切换到下一首；任意登录用户可调用，仅校验队列项一致性 |
| `autoPassSong(payload, user)` | 播放资源失效时自动切歌（系统行为，不校验房主） |
| `finishSong(payload)` | 处理歌曲自然结束并推进队列 |
| `switchToNextSong(room, options)` | 移除当前播放歌曲并切到队列下一首；`autoPass` 传入 `refillWhenEmpty` 时会先补一次歌再切，避免唯一歌曲失效后队列直接清空 |
| `refillQueue(payload, user)` | 自动补歌：正常模式「我的歌曲收藏 / 缓存 / 客户端 WS 提示词候选」按 5:3:2 随机混入队列；儿歌模式「儿歌收藏 / 客户端 WS 词池候选」按 3:2。候选由小程序搜索后提交，云函数不再请求音乐接口 |
| `getFavoriteSongs(user, childrenOnly)` | 收藏候选：`childrenOnly` 为真只取标记为儿歌的收藏，否则排除儿歌收藏（与收藏页「我的歌曲 / 儿歌」互斥语义一致） |
| `setChildrenMode(payload, user)` | 一键儿歌开关：开启时置位、清空队列并优先播放一首「儿歌」收藏；没有收藏时返回 `has_song: false`，由客户端通过 WS 搜索首曲 |
| `getNeteaseLyric(mid)` | 调用网易云官方歌词接口并解析为播放器歌词结构，带 30 分钟缓存 |
| `getNeteaseCovers(mids)` | 调用网易云官方歌曲详情接口补全缺失封面，单次最多 30 个，命中缓存 24 小时 |
| `getRealtimeState(payload, user)` | 一次返回默认房间和初始消息 |
| `exports.main(event)` | 获取可信 OPENID 并分发业务动作；识别 `refillPlaybackQueue` 定时触发器 |

## 首页初始化

| 函数 | 作用 |
| --- | --- |
| `onLoad()` | 初始化播放器并静默查询当前微信用户对应的业务账号 |
| `getMyInfo(reloadRoom)` | 调用云函数加载已有用户；不存在时保留登录入口 |
| `getRoomInfo()` | 加载固定默认房间、历史消息并建立实时监听 |
| `watchCloudData()` | 监听 `messages` 和 `rooms` 集合 |
| `closeCloudWatchers()` | 页面卸载时关闭数据库监听器 |

首页固定使用 `room_id = 1`，不再从场景参数或 Storage 读取房间号。

## 实时监听

`watchCloudData()` 建立两个数据库监听器：

- `messages`：按时间排序后映射为聊天消息，并保留最近 `historyMax` 条。
- `rooms`：更新默认房间资料；`current_song` 发生变化时调用 `playMusic()`。

首页使用云数据库监听房间和消息；网易云歌单、用户及歌单详情页使用 `utils/jusicWsApi.js` 的 SockJS + STOMP WebSocket 客户端。

## 音乐函数

| 函数 | 作用 |
| --- | --- |
| `getMusicLrc()` | 优先读取歌曲对象自带歌词，否则调用云函数 |
| `playMusic(msg)` | 请求云函数解析歌曲播放地址，然后控制背景播放器 |
| `showSongMenu()` | 显示收藏、切歌和音乐开关操作 |
| `tapToAddSong()` | 驾驶模式收藏当前歌曲 |
| `longPressPassTheSong()` | 驾驶模式切换歌曲 |

歌曲必须包含 `mid`、`name`，播放地址必须是 HTTPS 或云文件地址。

## 消息函数

| 函数 | 作用 |
| --- | --- |
| `getMessageList()` | 通过云函数加载初始历史消息 |
| `sendMessage(e)` | 乐观展示文本消息并调用云函数写入数据库 |
| `chooseImage()` | 上传图片到云存储并发送云文件 ID |
| `startVoiceRecord()` / `stopVoiceRecord()` | 按住开始录音，松开后停止并发送 |
| `uploadVoice(result)` | 上传语音到云存储并发送文件 ID、时长和引用 ID |
| `playVoice(e)` | 使用 `InnerAudioContext` 播放聊天语音 |
| `longTapToMessage(e)` | 提供撤回和引用操作 |
| `autoScroll()` | 将聊天视图滚动到底部 |

消息写入后由数据库监听刷新正式列表。请求失败时会移除本地临时消息并恢复输入内容。

## 导航与交互

`mainMenuClicked()` 保留驾驶、点歌、已点（播放队列）、收藏、提示词和分享入口。

## 用户页面

| 函数 | 页面 | 作用 |
| --- | --- | --- |
| `chooseWechatAvatar(e)` | 登录 | 上传微信头像并创建或读取用户 |

云函数使用微信身份上下文识别用户，客户端不能主动切换该身份。
