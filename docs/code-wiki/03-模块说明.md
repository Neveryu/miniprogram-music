# 模块说明

> 当前业务使用唯一默认房间，房间选择和房间管理模块不再参与应用入口。服务端业务集中到 `cloudfunctions/musicApp`。

## 应用模块

### `app.js`

职责：

- 创建全局应用实例。
- 保存用户和默认房间信息。
- 将 `request` 暴露为 `app.request`。
- 启动时检查版本并初始化云开发。
- 提供用户变化监听、资料完善提示和登录跳转。

关键依赖：`utils/request.js`、`utils/core.js`、`wx.cloud` 和路由 API。

### `app.json`

职责：

- 注册页面和首屏入口。
- 开启深色模式和主题文件。
- 声明后台音频能力。
- 注册 WechatSI 插件。
- 配置窗口样式和可调整窗口大小。

## 配置模块

### `config/index.js`

保存聊天 UI 配置：消息历史上限、输入提示、按钮标题和 30 个 Emoji 资源路径。

### `config/api.js`

保存当前用户、默认房间、历史消息和收藏歌曲等核心动作名。

### `cloudfunctions/musicApp`

- 通过 OPENID 查询或创建用户。
- 自动创建唯一默认房间。
- 处理聊天、资料、在线用户、播放队列和收藏歌单。
- 执行参数、资源地址和权限校验。
- 提供第三方音乐接口适配入口。

## 首页模块

### `pages/index/index.js`

首页是系统核心，承担以下职责：

- 初始化当前用户和房间。
- 监听云数据库消息和默认房间状态。
- 加载和维护聊天记录。
- 发送文本、图片、Emoji、引用和 @ 消息。
- 控制背景音乐、歌词和播放进度同步。
- 管理菜单、播放器和输入面板状态。
- 打开歌曲、用户和驾驶模式页面。
- 处理子页面 EventChannel 回调。

### `pages/index/index.wxml`

渲染聊天消息、系统消息、引用消息、播放器、登录遮罩和密码输入区域。消息根据 `text`、`img`、`link`、`jump`、`system` 等类型分支展示。

### `pages/index/template/footer-toolbar.wxml`

首页输入工具栏模板，包含输入框、发送按钮、Emoji 面板、图片选择和功能菜单。

### `pages/index/template/car-model.wxml`

首页内保留的驾驶模式模板。当前主要驾驶模式已由独立页面 `pages/song/car-mode` 承担。

## 歌曲模块

### `pages/song/select.js`

- 搜索歌曲。
- 点歌到当前房间。
- 收藏歌曲。
- 房主或管理员立即播放歌曲。

主要接口：`song/search`、`song/addSong`、`song/addMySong`、`song/playSong`。

### `pages/song/playing.js`

- 获取当前播放队列。
- 将歌曲置顶。
- 移除队列歌曲。
- 收藏或立即播放歌曲。
- 根据房主、管理员和点歌人判断菜单权限。

主要接口：`song/songList`、`song/push`、`song/remove`、`song/addMySong`、`song/playSong`。

### `pages/song/my.js`

- 分页加载个人收藏歌单。
- 从歌单点歌。
- 删除收藏。
- 房主或管理员立即播放。

主要接口：`song/mySongList`、`song/addSong`、`song/deleteMySong`、`song/playSong`。

### `pages/song/car-mode.js`

- 展示简化歌曲和歌词信息。
- 通过 EventChannel 接收首页推送的歌曲状态。
- 将收藏、切歌和退出操作委托给首页。
- 不直接发起歌曲业务请求。

## 房间模块

`pages/room` 下保留迁移前源码，但未在 `app.json` 注册。当前默认房间由云函数自动创建，不提供客户端房间选择、创建或设置功能。

## 用户模块

### `pages/user/login.js`

- 调用 `musicApp` 云函数。
- 由云函数读取 OPENID 并查询或创建用户。
- 触发全局用户变化监听。

主要接口：`weapp/wxAppLogin`。

### `pages/user/motify.js`

- 获取当前用户资料。
- 修改昵称、性别等资料。
- 上传头像到云存储。
- 同步用户资料。
- 通过 `myInfoChanged` 通知首页刷新。

主要动作：`user/getmyinfo`、`user/updateMyInfo`。

### `pages/user/online.js`

- 获取当前房间在线用户。
- @ 用户或发送互动。
- 长按管控功能在单房间版本中暂不提供。

主要动作：`user/online`、`message/touch`。

## 工具模块

### `utils/request.js`

统一云函数调用封装，处理 Loading、业务状态码、登录提示和云服务失败提示。

### `utils/core.js`

使用小程序 UpdateManager 检查新版本，在更新下载完成后提示用户并调用 `applyUpdate()`。

### `utils/helper.wxs`

在 WXML 视图线程提供：

- URL 解码。
- 静态资源地址转换。
- 图片宽度或布局判断。
- 友好时间格式化。

## 样式与资源

- `style/weui.wxss`：项目内置 WeUI 样式。
- `style/font/`：iconfont 字体资源。
- `res/Emojis/`：30 个聊天 Emoji。
- `res/image/`：Logo、播放器、默认头像等图片。
- `theme.json`：深色和浅色主题变量。
