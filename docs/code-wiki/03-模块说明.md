# 模块说明

> 当前业务使用唯一默认房间，房间选择和房间管理模块不再参与应用入口。服务端业务集中到 `cloudfunctions/musicApp`。

## 应用模块

### `app.js`

职责：

- 创建全局应用实例。
- 保存用户和默认房间信息。
- 将 `request` 暴露为 `app.request`。
- 启动时检查版本并初始化云开发。
- 提供登录回调注册、本地用户缓存和登录跳转。

关键依赖：`utils/request.js`、`utils/core.js`、`wx.cloud` 和路由 API。

### `app.json`

职责：

- 注册页面和首屏入口。
- 开启深色模式和主题文件。
- 声明后台音频能力。
- 配置窗口样式和可调整窗口大小。

## 配置模块

### `config/index.js`

保存聊天 UI 配置：消息历史上限、输入提示、按钮标题和 30 个 Emoji 资源路径。

### `config/api.js`

保存当前用户、默认房间、历史消息和收藏歌曲等核心动作名。

### `cloudfunctions/musicApp`

- 通过 OPENID 静默查询已有用户，仅在头像登录动作中创建新用户。
- 自动创建唯一默认房间。
- 处理聊天、播放队列和歌曲收藏。
- 执行参数、资源地址和权限校验。
- 提供网易云歌词获取入口（搜索与播放直链由客户端 WS 负责）。
- 自动补歌：队列不足时合并「我的歌曲收藏 / 房间缓存 / 客户端 WS 提示词候选」并按权重 5:3:2 随机混入（收藏来源与收藏页互斥分类一致，排除已标为儿歌的收藏），支持 `refillPlaybackQueue` 定时触发器。
- 一键儿歌：`room/setChildrenMode` 开启后清空队列并优先播放儿歌收藏，自动补歌来自「儿歌收藏 / 客户端 WS 词池候选」按权重 3:2 加权。

## 首页模块

### `pages/index/index.js`

首页是系统核心，承担以下职责：

- 初始化当前用户和房间。
- 监听云数据库消息和默认房间状态。
- 加载和维护聊天记录。
- 发送文本、图片、语音、Emoji、引用和 @ 消息。
- 控制背景音乐、歌词和播放进度同步。
- 管理菜单、播放器和输入面板状态。
- 打开歌曲、用户和驾驶模式页面。
- 处理子页面 EventChannel 回调。

### `pages/index/index.wxml`

渲染聊天消息、引用消息、播放器和登录遮罩。消息根据 `text`、`img`、`voice` 等类型分支展示。

### `pages/index/template/footer-toolbar.wxml`

首页输入工具栏模板，包含文字输入、按住录音、Emoji 面板、图片选择和功能菜单。

### `pages/index/template/car-model.wxml`

首页内保留的驾驶模式模板。当前主要驾驶模式已由独立页面 `pages/song/car-mode` 承担。

## 歌曲模块

### `pages/song/select.js`

- 搜索歌曲（支持网易云和 QQ 音乐；酷狗入口已隐藏；所有平台搜索和点播都走 jusic-serve WebSocket）。
- 搜索网易云/QQ 歌单和网易云用户，打开歌单详情。
- 点歌到当前房间；点歌/播放前统一经 `/music/pick` 获取播放直链。
- 收藏歌曲。
- 房主可立即播放歌曲。

主要接口：`song/addSong`、`song/addMySong`、`song/playSong`；搜索和点歌直链使用 `utils/jusicWsApi.js`。

### `pages/song/playing.js`

- 获取当前播放队列。
- 将歌曲置顶。
- 移除队列歌曲。
- 收藏或立即播放歌曲。
- 房主可置顶歌曲，房主或点歌人可移除自己的队列项。

主要接口：`song/songList`、`song/push`、`song/remove`、`song/addMySong`、`song/playSong`。

### `pages/song/my.js`

- 分页加载歌曲收藏（每页 30 条，触底加载下一页，返回不足一页时停止）。
- 顶部「我的歌曲 / 儿歌」分类 tab（固定顶部，各占一半）：两个分类互斥，标记为儿歌的收藏从「我的歌曲」移出，只在「儿歌」中显示；切换标签重置分页并重新加载。
- 列表最右侧胶囊按钮在「我的歌曲」与「儿歌」之间移动歌曲（「我的歌曲」显示「加入儿歌 ›」，「儿歌」显示「‹ 移出儿歌」），操作后该首立即离开当前列表。
- 从收藏列表点歌。
- 删除收藏（删除后回到第一页刷新）。
- 房主可立即播放。

主要接口：`song/mySongList`、`song/addSong`、`song/deleteMySong`、`song/playSong`、`song/toggleMySongChildren`。

### `pages/song/children.js`

- 儿歌乐园：8 个分类共 101 首内置曲库（经典、摇篮曲、动物、国学、英文、律动、动画、节日），蜡笔绘本风格。
- 点击歌曲通过 WS 按关键词搜索网易云取第一首点播；「随机来一首」在当前分类内随机。
- 底部「一键儿歌」主按钮：调 `room/setChildrenMode` 开关儿歌模式（需登录），开启后返回首页；没有儿歌收藏时由客户端通过 WS 搜索首曲并播放。
- 首页播放器开启儿歌模式后转为彩色特效形态（彩虹流光背景、跑马灯、呼吸光晕，由 `roomInfo.children_mode` 经 room watch 实时同步）。

主要接口：`song/addSong`、`room/getRoomInfo`、`room/setChildrenMode`；搜索和点歌直链使用 `utils/jusicWsApi.js`。

### `pages/song/car-mode.js`

- 独立单屏驾驶模式页面，整页无纵向滚动。
- 通过 EventChannel 接收首页推送的歌曲状态、歌词列表和当前行索引。
- 顶部信息卡展示歌曲信息、时钟（时间、日期、星期）和操作提示。
- 歌词区域固定视口，通过 `translateY` 动画滚动到当前行。
- 支持滑动切歌、点击收藏（心形呼吸/爆点动画）等手势操作。
- 将收藏、切歌和退出操作委托给首页，不直接发起歌曲业务请求。

## 房间模块

### `pages/room/prompts.js`

- 房主管理搜索提示词（增删，最多 20 个）。
- 提示词用于自动补歌兜底搜索。

主要接口：`room/getSearchPrompts`、`room/updateSearchPrompts`。

## 用户模块

### `pages/user/login.js`

- 调用 `musicApp` 云函数。
- 由云函数读取 OPENID 并查询或创建用户。
- 登录成功后通过 `app.notifyLogin` 写入本地缓存并通知订阅了登录事件的页面刷新。

主要接口：`weapp/wxAppLogin`。

- 登录前必须勾选协议同意；未勾选时点击登录会抖动勾选框并弹窗提示，不再用透明遮罩拦截点击。
- 协议与隐私政策通过独立页面完整展示（`pages/user/agreement`）。
- 通过 `wx.getPrivacySetting` 查询微信侧隐私授权状态，仅用于提示；未授权时点击 `open-type="chooseAvatar"` 按钮会自动弹出微信官方隐私指引，同意后继续选择头像，无需二次点击；`wx.openPrivacyContract` 提供查看入口。
- 使用 `chooseAvatar` 选择并上传微信头像，登录时携带当前协议版本，云函数强制校验版本。
- 头像上传成功后自动调用登录动作；登录校验失败（422）会删除刚上传的头像，网络异常时保留以免误删已建号的头像。
- 老用户保留原资料，新用户使用默认昵称；登录后不再提供资料编辑入口，头像只在登录时设置一次。

### `pages/user/agreement.js`

- 按 `type` 参数（`service`/`privacy`）展示《用户服务协议》或《隐私政策》全文。
- 供登录页和审核要求使用，静态内容页面。

## 工具模块

### `utils/request.js`

统一云函数调用封装，处理 Loading、业务状态码、登录提示和云服务失败提示。

### `utils/jusicWsApi.js`

jusic-serve 的 SockJS + STOMP WebSocket 客户端，供搜歌页、用户歌单页、歌单详情页和首页播放使用：

- SockJS `o` 开放帧与 STOMP `CONNECT`/`CONNECTED` 握手。
- 业务请求按响应类型串行关联，支持取消、超时和重连。
- 提供网易云/QQ/电台搜索、歌单和用户查询，以及 `/music/pick` 播放直链。
- 将原始字段转换为页面统一结构。

### `utils/cover.js`

批量补全网易云缺失封面：收集歌曲中的数值 `mid`，分批调用云函数 `song/getCovers`，把返回的封面写回歌曲对象。

### `utils/childrenKeywords.js`

儿歌模式自动补歌关键词池，提供 1 个聚合词 + 2 个具体歌名的随机组合。

### `utils/core.js`

使用小程序 UpdateManager 检查新版本，在更新下载完成后提示用户并调用 `applyUpdate()`。

### `utils/helper.wxs`

在 WXML 视图线程提供：

- URL 解码。
- 静态资源地址转换。
- 图片宽度或布局判断。
- 友好时间格式化。
