# 项目概览

> 当前版本已迁移到微信云开发，并收敛为单一默认房间。旧后端分析仅作为历史背景，最新状态见 [云开发迁移说明](../cloud-development.md)。

## 项目定位

Music For U 是一个原生微信小程序音乐聊天室客户端。用户可以在唯一公共房间聊天、搜索和点播第三方音乐 API 的歌曲、管理播放队列、收藏歌曲，并在驾驶模式下使用简化界面和语音播报。

## 技术栈

| 类别 | 技术 |
| --- | --- |
| 客户端框架 | 微信小程序原生框架 |
| 逻辑语言 | JavaScript |
| 视图与样式 | WXML、WXSS、WXS |
| 云函数 | `wx.cloud.callFunction` |
| 文件上传 | `wx.cloud.uploadFile` |
| 实时通信 | 云数据库 `watch` |
| 音乐播放 | `wx.getBackgroundAudioManager` |
| 语音播报 | WechatSI `textToSpeech` |
| 页面通信 | EventChannel、`App.globalData` |
| 本地持久化 | `wx.getStorageSync`、`wx.setStorageSync` |
| UI 资源 | 内置 WeUI、iconfont、静态图片与字体 |

## 核心业务能力

| 业务域 | 能力 |
| --- | --- |
| 用户 | 微信身份、协议同意登录、资料编辑、头像上传 |
| 房间 | 唯一公共房间、默认房主、搜索提示词管理和当前歌曲 |
| 聊天 | 历史消息、文本、图片、语音、引用回复和撤回 |
| 音乐 | 搜索、点歌、收藏分页、队列管理、切歌、歌词和进度同步 |
| 自动补歌 | 收藏、房间缓存和提示词三级来源的队列补充 |
| 实时事件 | 房间更新、消息和歌曲状态 |
| 驾驶模式 | 独立单屏页面、时钟、歌词滚动、收藏、切歌和语音播报 |

## 架构特征

- **单体客户端**：所有客户端功能位于一个原生小程序工程中。
- **胖首页**：`pages/index/index.js` 是应用编排中心，承担多个领域职责。
- **云函数 + 云数据库**：云函数提交操作，数据库监听驱动实时消息和歌曲状态更新。
- **弱分层**：页面直接调用 `app.request`，不存在独立 Service、Repository、Store 或 Model 层。
- **隐式模型**：没有 TypeScript、DTO 或 Schema，数据结构由接口返回字段和页面访问方式约定。
- **多种共享机制**：全局状态、页面状态、本地缓存和 EventChannel 并存。

## 仓库边界

仓库不包含 jusic-serve 和 Meting-API 的服务端实现，也不包含自动化测试与 CI/CD 流水线。业务由 `cloudfunctions/musicApp` 提供；普通歌曲搜索、播放地址和歌词通过云函数访问 Meting-API，网易云歌单、用户和用户公开歌单由小程序通过 `utils/jusicWsApi.js` 访问 jusic-serve WebSocket。

## 当前完整性说明

`app.json` 注册首页、微信登录、用户协议与隐私政策、资料、歌曲搜索、网易云/QQ 歌单搜索、网易云用户搜索、用户歌单、歌单详情、播放队列、歌曲收藏、驾驶模式和搜索提示词管理页面。旧房间选择、房间管理和在线用户页面已从源码移除，仅保留默认房主使用的提示词管理页。
