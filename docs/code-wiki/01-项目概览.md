# 项目概览

> 当前版本已迁移到微信云开发，并收敛为单一默认房间。旧后端分析仅作为历史背景，最新状态见 [云开发迁移说明](../cloud-development.md)。

## 项目定位

Music For U 是一个原生微信小程序音乐聊天室客户端。用户可以进入房间聊天、搜索和点播歌曲、管理播放队列、收藏歌曲、切换房间，并在驾驶模式下使用简化界面和语音播报。

仓库根目录的 `README.md` 提到系统还支持 OAuth、私人房间、房间加密和域名绑定等能力，但当前仓库仅包含微信小程序客户端，部分页面和后端能力并未完整包含。

## 技术栈

| 类别 | 技术 |
| --- | --- |
| 客户端框架 | 微信小程序原生框架 |
| 逻辑语言 | JavaScript |
| 视图与样式 | WXML、WXSS、WXS |
| HTTP | `wx.request` |
| 文件上传 | `wx.uploadFile` |
| 实时通信 | `wx.connectSocket` |
| 音乐播放 | `wx.getBackgroundAudioManager` |
| 语音播报 | WechatSI `textToSpeech` |
| 页面通信 | EventChannel、`App.globalData` |
| 本地持久化 | `wx.getStorageSync`、`wx.setStorageSync` |
| UI 资源 | 内置 WeUI、iconfont、静态图片与字体 |

## 核心业务能力

| 业务域 | 能力 |
| --- | --- |
| 用户 | 游客访问、账号登录、资料编辑、头像上传、退出登录 |
| 房间 | 获取当前房间、热门房间、切换房间、房间密码、房间配置 |
| 聊天 | 历史消息、文本消息、图片消息、引用、@、撤回、互动 |
| 音乐 | 搜索、点歌、收藏、队列管理、切歌、歌词和进度同步 |
| 实时事件 | 用户加入、在线人数、房间更新、消息和歌曲事件 |
| 驾驶模式 | 简化播放器、收藏、切歌和语音播报 |

## 架构特征

- **单体客户端**：所有客户端功能位于一个原生小程序工程中。
- **胖首页**：`pages/index/index.js` 是应用编排中心，承担多个领域职责。
- **HTTP + WebSocket**：HTTP 提交操作，WebSocket 回推实时事实并驱动页面更新。
- **弱分层**：页面直接调用 `app.request`，不存在独立 Service、Repository、Store 或 Model 层。
- **隐式模型**：没有 TypeScript、DTO 或 Schema，数据结构由接口返回字段和页面访问方式约定。
- **多种共享机制**：全局状态、页面状态、本地缓存和 EventChannel 并存。

## 仓库边界

当前仓库不包含：

- API 服务端实现和数据库结构。
- WebSocket 服务端协议实现。
- OAuth 登录服务端流程。
- npm 依赖和包管理配置。
- 命令行构建、测试、检查和发布脚本。
- 自动化测试与 CI/CD 流水线。

## 当前完整性说明

`app.json` 仅注册首页、登录页和驾驶模式页，但源码中还存在并导航到多个未注册页面。代码还引用了仓库中不存在的 `pages/pc/index`、`pages/room/create`、`pages/user/profile`。因此当前仓库可能是裁剪版、迁移中版本或页面注册配置不完整的版本。
