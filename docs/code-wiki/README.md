## 快速认知

- 项目是原生微信小程序，不是 Taro、uni-app、React 或 Vue 工程。
- 产品形态是“音乐播放器 + 单房间实时聊天室”，支持聊天、点歌、播放队列、歌单和驾驶模式。
- 云函数用于业务操作，云数据库 `watch` 用于同步聊天和播放状态。
- `pages/index/index.js` 是核心控制器，同时承担聊天、播放器、数据库监听和导航职责。
- 跨页面状态主要保存在 `App.globalData`，业务数据保存在云数据库。
- 仓库没有 npm 依赖、命令行构建脚本、自动化测试或 CI/CD 配置。

3. 根据工作领域阅读[模块说明](./03-模块说明.md)和[关键类与函数](./04-关键类与函数.md)。
4. 联调时查阅[接口与数据模型](./05-接口与数据模型.md)。
5. 首次启动或发布时查阅[运行与发布](./07-运行与发布.md)。
