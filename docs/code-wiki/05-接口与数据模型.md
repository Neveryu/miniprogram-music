# 接口与数据模型

## 云函数调用约定

```javascript
app.request({
  url: 'room/getRoomInfo',
  loading: '加载中',
  data: {
    room_id: 1
  },
  success(res) {},
  error(res) {},
  fail(err) {}
})
```

`utils/request.js` 保留原页面回调模型，但内部使用 `wx.cloud.callFunction`：

```text
name: musicApp
data.action: 原业务动作名
data.payload: 页面业务参数
```

## 统一响应模型

客户端假定所有 API 返回：

```text
{
  code: Number,
  msg: String,
  data: Any
}
```

| 业务码 | 客户端处理 |
| --- | --- |
| `200` | 调用业务 `success` |
| `401` | 调用自定义登录处理或跳转登录页 |
| `403` | 权限不足 |
| `422` | 参数校验失败 |
| 其他 | 调用 `error` 或显示统一错误弹窗 |

## API 清单

以下清单根据当前客户端调用整理。

### 用户接口

| 接口 | 用途 |
| --- | --- |
| `weapp/wxAppLogin` | 校验头像、昵称、性别和签名，创建或更新当前 OPENID 对应用户 |
| `user/getmyinfo` | 获取已完成手动登录的当前用户 |
| `user/updateMyInfo` | 更新用户资料 |

### 房间接口

| 接口 | 用途 |
| --- | --- |
| `room/getRoomInfo` | 获取当前房间信息 |

### 歌曲接口

| 接口 | 用途 |
| --- | --- |
| `song/search` | 搜索歌曲 |
| `song/addSong` | 加入播放队列 |
| `song/addMySong` | 收藏歌曲 |
| `song/deleteMySong` | 删除收藏 |
| `song/mySongList` | 获取歌曲收藏 |
| `song/songList` | 获取房间播放队列 |
| `song/playSong` | 立即播放 |
| `song/push` | 歌曲置顶 |
| `song/remove` | 移除队列歌曲 |
| `song/pass` | 房主或当前点歌人切歌 |
| `song/getLrc` | 获取歌词 |

### 消息接口

| 接口 | 用途 |
| --- | --- |
| `message/getMessageList` | 获取历史消息 |
| `message/send` | 发送文字、图片或语音，可携带引用消息 ID |
| `message/back` | 撤回消息 |
| `message/clear` | 清空房间历史 |

### 附件接口

| 接口 | 用途 |
| --- | --- |
| `attach/search` | 搜索图片或表情资源 |
聊天图片、语音和头像不经过云函数动作，直接上传云存储。

## 实时协议

客户端通过云数据库 `watch` 监听：

- `messages` 中 `room_id = 1` 的消息变化。
- `rooms` 中 `room_id = 1` 的当前歌曲变化。

客户端具有登录后读取权限，但不允许直接写数据库；所有写操作通过云函数进行。

## 文件上传

聊天图片、语音和头像使用 `wx.cloud.uploadFile`。数据库保存 `cloud://` 文件 ID，语音消息同时保存毫秒时长。

## 隐式数据模型

项目没有类型定义，以下字段根据客户端访问归纳。

### 用户 User

| 字段 | 含义 |
| --- | --- |
| `_id` / `user_id` | 云数据库用户文档 ID |
| `user_name` | 昵称 |
| `user_head` | 头像地址 |
| `user_sex` | 性别 |
| `user_remark` | 个性签名 |
| `profile_completed` | 是否已完善资料 |

`_openid` 只保存在服务端用户文档中，不包含在客户端用户对象里。

### 房间 Room

| 字段 | 含义 |
| --- | --- |
| `room_id` | 固定为 `1` |
| `room_name` | 房间名称 |
| `room_user` | 唯一房主用户 ID；首位创建默认房间的用户 |
| `room_type` | 房间类型 |
| `room_notice` | 房间公告 |
| `room_public` | 公开或加密设置 |
| `room_addsong` | 点歌权限 |
| `room_sendmsg` | 发言权限 |
| `room_playone` | 播放模式 |
| `current_song` | 当前播放队列项 |

### 歌曲 Song

| 字段 | 含义 |
| --- | --- |
| `mid` | 歌曲媒体 ID |
| `name` | 歌曲名 |
| `singer` | 歌手 |
| `pic` | 封面 |
| `url` | HTTPS 或云文件播放地址 |
| `lrc` | 歌词数组 |

### 消息 Message

| 字段 | 含义 |
| --- | --- |
| `type` | `text`、`img` 或 `voice` |
| `content` | 消息内容 |
| `user` | 发送用户 |
| `message_id` | 消息 ID |
| `message_time` | 消息时间 |
| `resource` | 图片或语音云文件 ID |
| `duration` | 语音时长，单位毫秒 |
| `reply` | 被引用消息的最小快照 |
| `loading` | 本地临时消息标记 |

云数据库消息文档使用 `payload` 保存展示结构，并保存 `created_timestamp` 供排序和友好时间显示。

客户端发送引用时只提交 `reply_to`。云函数读取原消息后生成 `reply`，其中仅保存消息 ID、类型、文字摘要和发送者昵称，不复制完整原消息。

## 鉴权流程

1. 应用使用 `config/cloud.js` 中的显式环境 ID 初始化 `wx.cloud`。
2. 客户端调用 `musicApp` 云函数，不传 OPENID。
3. 云函数通过 `cloud.getWXContext()` 获取可信 OPENID。
4. 云函数根据 OPENID 查询或创建用户。
5. 数据库写操作在云函数中执行，客户端不能伪造其他用户身份。

## 缓存策略

- 消息只保存在页面内存中，最多保留 `historyMax = 20` 条。
- 用户和房间同时存在页面状态与全局状态两份副本。
- 云数据库是业务数据的唯一持久化来源。
