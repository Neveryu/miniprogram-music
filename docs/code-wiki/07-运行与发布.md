# 运行与发布

## 前置条件

- 当前 AppID 已开通并关联云开发环境。
- 云环境中具备数据库、云函数和云存储能力。
- WechatSI 插件对当前 AppID 可用。
- 音乐 API 接入前需取得接口文档和合法资源使用授权。

## 云资源准备

1. 创建 `users`、`rooms`、`messages`、`play_queue`、`playlists` 集合。
2. 参考 `database.indexes.json` 创建唯一索引和复合索引。
3. 将数据库客户端权限设置为登录用户可读、客户端不可写。
4. 部署 `cloudfunctions/musicApp` 并安装云端依赖。
5. 确认云存储允许小程序上传并允许业务用户读取文件。

详细清单见 [云开发迁移说明](../cloud-development.md)。

## 启动检查

1. `wx.cloud.init()` 不报错。
2. `weapp/wxAppLogin` 能自动创建 `users` 文档。
3. 首次访问能自动创建 `rooms` 中的默认房间。
4. `messages.watch()` 和 `rooms.watch()` 不出现权限错误。
5. 文本消息能写入并实时显示。
6. 头像与聊天图片能上传并读取。

## 常见问题

### 云服务连接失败

- 检查项目是否关联正确云环境。
- 检查 `musicApp` 云函数是否已部署。
- 检查云函数依赖是否安装完成。
- 查看云函数日志中的动作名和异常。

### 数据库监听失败

- 确认集合已创建。
- 确认登录用户具备读取权限。
- 确认 `messages` 和 `rooms` 的查询字段存在。
- 确认复合索引已创建并生效。

### 没有声音

- 确认 `requiredBackgroundModes` 包含 `audio`。
- 检查歌曲对象是否包含合法 HTTPS `url`。
- 检查用户是否关闭音乐开关。
- 检查背景音频权限和设备表现。

### 搜歌不可用

`https://www.hanxin.vip/api/music` 当前对已测试的常见请求参数返回空响应。需要接口文档、鉴权信息和响应示例后才能完成 `searchMusic` 适配。
