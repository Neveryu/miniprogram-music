# 运行与发布

## 前置条件

- 当前 AppID 已开通并关联云开发环境。
- 云环境中具备数据库、云函数和云存储能力。
- WechatSI 插件对当前 AppID 可用。
- 音乐 API 接入前需取得接口文档和合法资源使用授权。

## 云资源准备

1. 创建 `users`、`rooms`、`messages`、`play_queue`、`playlists` 集合。
2. 参考 `cloudfunctions/musicApp/database.indexes.json` 创建唯一索引和复合索引。
3. 将数据库客户端权限设置为登录用户可读、客户端不可写。
4. 部署 `cloudfunctions/musicApp` 并安装云端依赖；注意云函数默认 3 秒超时，外部音乐接口调用可能需要调大超时时间。
5. 按需配置定时触发器 `refillPlaybackQueue` 启用周期性自动补歌。
6. 将云存储权限设置为「所有用户可读，仅创建者可写」，确认跨用户头像和消息附件可读。

详细清单见 [云开发迁移说明](../cloud-development.md)。

## 启动检查

1. `wx.cloud.init()` 不报错。
2. 已有用户能通过 `user/getmyinfo` 静默进入；新用户须勾选协议同意并选择头像后由 `weapp/wxAppLogin` 创建；协议页可从登录页正常打开。
3. 首次访问能自动创建 `rooms` 中的默认房间。
4. `messages.watch()` 和 `rooms.watch()` 不出现权限错误。
5. 文本消息能写入并实时显示。
6. 头像、聊天图片与语音能上传并读取（跨用户头像正常显示，他人不显示占位图）。

## 常见问题

### 云服务连接失败

- 检查项目是否关联正确云环境。
- 检查 `musicApp` 云函数是否已部署。
- 检查云函数依赖是否安装完成。
- 查看云函数日志中的动作名和异常。

### 数据库监听失败

- 确认集合已创建。
- 确认登录用户具备读取权限。
- 确认 `messages` 和 `rooms` 的查询字段存在。
- 确认复合索引已创建并生效。

### 没有声音

- 确认 `requiredBackgroundModes` 包含 `audio`。
- 检查歌曲对象是否包含合法 HTTPS `url`。
- 检查用户是否关闭音乐开关。
- 检查背景音频权限和设备表现。

### 搜歌不可用

音乐接口按平台路由：网易云走 `https://meting.mikus.ink/api`，QQ 音乐、酷狗和网易云电台走 `https://api.i-meto.com/meting/api`，当前无备用回退接口；网易云/QQ 歌单、用户和歌单详情使用 `wss://xin.hanxin.vip` 的 WebSocket 通道。详细请求参数、响应结构和部署限制见 [meting-api.md](../meting-api.md)。发布前应验证歌曲搜索、歌单搜索、用户歌单、歌单详情、播放地址、封面和歌词在目标环境可用。

## 验证清单

1. 已有微信用户静默加载、新用户协议同意登录、资料后续修改。
2. 默认房间自动创建。
3. 历史消息、实时消息和撤回。
4. 文本、图片、语音、Emoji、引用和 @。
5. 播放队列、歌曲收藏分页、置顶（房主）、移除（房主或点歌人）和切歌（任意登录用户）。
6. 自动补歌：收藏、缓存、提示词三级来源和定时触发器。
7. 背景音频、歌词和驾驶模式（单屏无滚动、时钟、手势操作）。
8. 云函数异常、权限异常和网络断开提示。
9. jusic-serve SockJS/STOMP 握手、并发请求串行化、取消、超时和重连。
10. 在微信公众平台配置 `xin.hanxin.vip` 的 request 和 socket 合法域名，并在开发者工具与真机验证 TLS 连接。

## 自动化现状

仓库没有单元测试、集成测试、UI 自动化、lint 和 CI/CD。当前验证依赖 JavaScript 语法检查、JSON 解析检查、编辑器诊断和核心流程回归。
