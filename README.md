# Music For U

基于微信云开发的单房间音乐聊天室小程序，围绕家庭亲子场景提供一起点歌、听歌和聊天。

## 当前架构

- 微信身份：云函数通过 `OPENID` 自动识别用户，客户端不保存登录 token。
- 登录方式：新用户首次登录须勾选协议、完成微信《小程序用户隐私保护指引》授权并选择微信头像；登录后不提供资料编辑入口，头像只在登录时设置。
- 业务服务：`cloudfunctions/musicApp` 统一处理用户、消息、歌曲队列、收藏和房间状态。
- 数据存储：云数据库保存用户、默认房间、消息、播放队列和歌曲收藏。
- 实时同步：客户端通过云数据库 `watch` 监听消息和当前歌曲。
- 文件资源：头像、聊天图片和语音上传到云存储。
- 房间模型：仅保留一个默认房间，不提供创建、搜索和切换房间。
- 房主规则：首位访问并创建默认房间的用户成为唯一房主。
- 消息能力：支持文字、图片、语音和引用回复，不提供审核或举报流程。
- 插件依赖：不依赖第三方插件；原 WechatSI 语音播报已移除，驾驶模式仅保留视觉信息。

## 核心功能

- 登录合规：登录必须携带协议版本，云函数强制校验并记录 `agreement_version` / `agreed_at`；微信隐私授权由 `chooseAvatar` 触发官方指引弹窗，同意后继续选择头像。
- 歌曲收藏：按 30 条分页加载，支持点歌、移除和房主立即播放。
- 收藏分类：收藏页分为「我的歌曲 / 儿歌」，两者互斥；每行右侧胶囊按钮可直接「加入儿歌」或「移出儿歌」。
- 儿歌乐园：内置经典儿歌、摇篮曲、动物儿歌、国学启蒙、英文儿歌、律动儿歌、动画经典和节日日常分类曲库，点击按关键词搜索点播，支持随机来一首；一键儿歌模式开启后清空队列立即播放儿歌。
- 自动补歌：正常模式从「我的歌曲收藏 / 房间缓存 / 搜索提示词候选」按权重（5:3:2）随机混入，提示词候选由客户端通过 WS 搜索后提交；儿歌模式在「儿歌收藏 / 客户端 WS 词池候选」之间按权重（3:2）补充，开启儿歌模式时优先取儿歌收藏。
- 儿歌词池：客户端每轮随机抽 1 个聚合词（儿歌、儿歌多多、贝乐虎儿歌等 14 个）和 2 个具体歌名词，通过 WS 并行搜索后合并打乱。
- 驾驶模式：独立单屏页面，含时钟、歌词滚动和手势操作，收藏与切歌委托首页处理；不再提供语音播报。
- QQ 音乐：搜索、歌单和用户歌单元数据走 jusic-serve WebSocket；点歌或播放前通过 `/music/pick` 获取服务端下发的签名直链，随歌曲入队，直链失效时由播放器错误回调触发自动切歌。
- 搜索平台：搜歌页提供「网易云 / QQ音乐」两个平台，网易云下可切换歌曲、歌单、用户、电台；酷狗入口已隐藏。所有平台的搜索和点播都走 jusic-serve WebSocket，播放地址由 `/music/pick` 下发。
- 提示词管理：房主维护搜索提示词（最多 20 个），用于自动补歌兜底搜索。

## 操作权限

| 操作 | 权限 |
| --- | --- |
| 点歌、收藏、加入/移出儿歌 | 任意登录用户（仅操作自己的收藏） |
| 切歌 | 任意登录用户 |
| 立即播放、置顶、清空消息、管理提示词 | 仅房主 |
| 移除队列歌曲 | 房主或点歌人 |
| 撤回消息 | 消息发送者或房主 |

## 音乐接口

音乐接口统一使用 jusic-serve WebSocket：所有平台的歌曲、歌单、用户和电台搜索都通过 `utils/jusicWsApi.js` 获取元数据，搜索接口不返回播放地址；点歌/播放前统一调用 `/music/pick` 获取带签名的播放直链并随歌曲入队，直链失效时先重新点播一次，仍失败再自动切歌。网易云搜索缺少封面时，由云函数 `song/getCovers` 调用网易云官方歌曲详情接口批量补全；歌词由云函数调用网易云官方歌词接口，QQ 音乐和电台暂不提供歌词。接口说明见 [docs/meting-api.md](docs/meting-api.md)。

## 当前限制

- 酷狗：在线播放链路已停用，搜歌页隐藏酷狗入口；历史队列和收藏中的酷狗歌曲仍会保留，但无法解析新的播放地址。
- QQ 音乐：播放依赖 jusic-serve 点播下发的直链；需要登录、购买或受地区版权限制的歌曲仍可能无法播放。
- 歌词：仅网易云通过官方歌词接口获取；QQ 音乐和电台歌曲显示暂无歌词。
- 隐私接口：需在小程序后台配置并发布《用户隐私保护指引》，声明头像/昵称、麦克风、选中的照片或视频、剪切板；缺少声明时相关接口会报 `errno 112`。
- 部署：修改云函数后需在微信开发者工具中重新上传并部署 `musicApp`；仅改前端时重新编译即可。
