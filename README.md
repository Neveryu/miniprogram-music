# Music For U

基于微信云开发的单房间音乐聊天室小程序。

## 当前架构

- 微信身份：云函数通过 `OPENID` 自动识别用户。
- 业务服务：`cloudfunctions/musicApp` 统一处理用户、消息、歌曲队列和收藏。
- 数据存储：云数据库保存用户、默认房间、消息、播放队列和歌曲收藏。
- 实时同步：客户端通过云数据库 `watch` 监听消息和当前歌曲。
- 文件资源：头像、聊天图片和语音上传到云存储。
- 房间模型：仅保留一个默认房间，不提供创建、搜索和切换房间。
- 房主规则：首位访问并创建默认房间的用户成为唯一房主。
- 消息能力：支持文字、图片、语音和引用回复，不提供审核或举报流程。

## 核心功能

- 登录合规：登录前须勾选协议同意，用户服务协议与隐私政策以独立页面完整展示，信息收集在用户授权后进行。
- 歌曲收藏：按 30 条分页加载，支持点歌、移除和房主立即播放。
- 驾驶模式：独立单屏页面，含时钟、歌词滚动和手势操作，收藏与切歌委托首页处理。
- 自动补歌：播放队列不足时按「用户收藏 → 房间缓存 → 搜索提示词」顺序补充可播放歌曲，支持定时触发器。
- 提示词管理：房主维护搜索提示词（最多 20 个），用于自动补歌兜底搜索。

## 操作权限

| 操作 | 权限 |
| --- | --- |
| 切歌 | 任意登录用户 |
| 立即播放、置顶、清空消息、管理提示词 | 仅房主 |
| 移除队列歌曲 | 房主或点歌人 |
| 撤回消息 | 消息发送者或房主 |

## 音乐接口

音乐接口按平台路由：网易云使用 `https://meting.mikus.ink/api`，QQ 音乐、酷狗和网易云电台使用 `https://api.i-meto.com/meting/api`，当前未配置备用回退接口。普通歌曲搜索、播放地址、封面和歌词通过 `musicApp` 云函数接入，QQ 播放地址由云函数按 `songmid` 调用 Meting 详情接口动态解析；网易云歌单、用户及歌单详情使用 `utils/jusicWsApi.js` 的 WebSocket 通道。接口说明见 [docs/meting-api.md](docs/meting-api.md)。
